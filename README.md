# Дашборд по данным из registrations.csv

Нужен только Python 3.9+ (ничего устанавливать не надо).

```bash
python3 server.py                  # читает registrations.csv рядом со скриптом
python3 server.py путь/к/файлу.csv # или любой другой файл
```

Откройте http://localhost:8000/. Файл перечитывается автоматически (раз в 10 секунд, если он изменился),
сервер сам файл **не меняет**. Кнопка «Открыть другой CSV» показывает чужой файл только в браузере.

Настройки: `PORT`, `HOST` (0.0.0.0 — доступ из сети), `CSV_PATH`,
`ADMIN_PASSWORD` и `ADMIN_USER` (доступ по логину и паролю).

Колонки CSV: `name, city, registered, source, ticket, paid` (также понимает русские названия: имя, город, дата, источник, билет, оплата).
